# Personal Portfolio

A personal portfolio website that I'm building from scratch to experiment with web development, UI design, and front-end development.

> 🚧 **Work in Progress** — This website is still actively being developed and will continue to evolve as I learn and improve.

## About

This project started as a challenge to see how far I could take a website **without relying on vibe coding or AI-generated code**.

The goal isn't just to make a portfolio that looks good, but to understand how each part of it works and improve it over time.

## Tech Stack

* **HTML5** — Structure and content
* **CSS3** — Styling, layout, animations, and responsiveness
* **JavaScript** — Planned for future interactive features
